Circuit geometry

Monza, Silverstone, Spa-Francorchamps, Suzuka, Bahrain (Sakhir) and Interlagos (São Paulo) use center lines and widths from the TUM FTM racetrack-database, Technical University of Munich, Chair of Automotive Technology. Its README credits Andressa de Paula Suiti for the width-extraction algorithm and Alexander Heilmeier as contact. The dataset is licensed under LGPL 3.0, incorporating GPL 3.0.

© OpenStreetMap contributors. The underlying map geometry is available under the Open Database License 1.0. The game’s derived circuit geometry remains subject to those data rights.

Changes include recentering and smoothing widths, resampling and length scaling, moving start positions, combining elevation and encoding values. Suzuka’s bridge clearance is estimated. These are game approximations, not official track surveys. The embedded circuit dataset is provided separately under its applicable LGPL/ODbL terms; these rights are not restricted by the game’s proprietary terms. Corresponding source and modification/replacement arrangements require release review.

Elevation

The build tool obtains Skadi tiles from AWS Terrain Tiles / Mapzen. The existing provenance record describes these as SRTM from NASA/USGS. Terrain Tiles blends multiple elevation sources, so the exact source and terms for each downloaded tile must be confirmed. See the terrain source attribution list. We do not claim the entire elevation dataset is public domain.
