# Pit UI screenshots

Captured fresh in Chromium at 1600 × 900, playing the real game simulation through its existing AI driving helper and pit autopilot. UI choices use the game’s buttons and keyboard controls. Simulation is advanced between screenshots; rendering is held for capture. No game source was changed.

Covers all three circuits: normal racing, physical pit entry, approach, pit lane, stopped tyre/fuel selection, tyre change, refuelling, service completion, pit exit, and the restored racing HUD. Supporting menu, settings, controls, race brief and strategy screens are included.

Additional busy-box, puncture and wing-repair scenarios are staged using the same simulation APIs as `tests/pitstops.cjs`. These screenshots are named `extra-*` and show the production UI; they are not painted or mocked.


Open [index.html](index.html) for the screenshot gallery. Each image below is full resolution.
